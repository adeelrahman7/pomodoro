# Pomodoro Timer

A Pomodoro timer that logs your focus sessions and shows weekly stats, with a
flip-clock web UI and a command-line version that share the same data.
The Python side is standard library only (pytest for the tests); the web UI is
built with React.

## Web UI

```bash
cd pomodoro
python server.py
```

This opens http://127.0.0.1:8000 in your browser (use `--port 8001` if 8000 is
taken, or `--no-browser` to skip opening a tab). Press Ctrl+C in the terminal to
stop the server. You don't need Node for this: the built site is already in `static/`.

- A flip clock counts down minutes and seconds; the small number in the corner
  is the cycle. The bar along the bottom turns green during breaks.
- Click **Stats** (or press **S**) to slide out the weekly stats; **Esc** closes it.
- **Space** starts or pauses, **F** goes full screen. While a session runs, the
  controls fade out after 3 seconds; move the mouse to bring them back.
- Stopping a work session (or closing the tab) after at least 1 minute logs it
  as stopped early. Paused time doesn't count toward your focus minutes.
- Allow notifications when asked to get a pop-up when a phase ends while the
  tab is in the background.
- Browsers slow down timers in background tabs, so the chime can come up to a
  minute late if the tab has been hidden a while. The logged times stay exact.

### Changing the front end

The UI is a React app in `frontend/` (Vite for building, framer-motion for the
flip and sidebar animations). You need [Node.js](https://nodejs.org) 18 or newer.

```bash
cd frontend
npm install          # once
npm run dev          # live-reloading dev server at http://localhost:5173
```

Keep `python server.py --no-browser` running in another terminal while you use
`npm run dev`; the dev server forwards `/api` calls to it. When you're happy,
run `npm run build`, which rebuilds `static/` for `server.py` to serve, and commit it.

## Command line

```bash
cd pomodoro

# 4 cycles of 25 min work / 5 min break
python main.py start --label "CS3360" --work 25 --break 5 --cycles 4

# Quick test run: 6-second phases
python main.py start --label test --work 0.1 --break 0.1 --cycles 2

# This week's stats, or last week's
python main.py summary
python main.py summary --week -1

# Most recent sessions
python main.py log --n 10
```

Press **Ctrl+C** to stop. A work session interrupted after at least 1 minute is
logged with `"completed": false`; shorter ones are discarded.

## Files

| File | What it does |
|------|--------------|
| `main.py` | Parses the `start`, `summary` and `log` commands |
| `timer.py` | Countdown loop, Ctrl+C handling, terminal bell |
| `storage.py` | Reads/writes `sessions.json` atomically (temp file + rename) |
| `summary.py` | Weekly totals, per-day bars, per-label totals, streak |
| `server.py` | Local web server: serves `static/` and a small JSON API |
| `frontend/` | React source for the web UI (`src/App.jsx`; `src/usePomodoro.js` has the timer logic) |
| `static/` | The built web UI (generated by `npm run build`, don't edit by hand) |
| `test_summary.py` | pytest tests with fake session data |
| `test_server.py` | Tests for the API's validation and a real HTTP round trip |

`sessions.json` is created on first run next to the scripts. If it's ever
unreadable, it's moved to `sessions.json.corrupt` and a fresh file is started.

## How the stats work

- Weeks run Monday to Sunday; a session belongs to the day it started.
- Total focus time includes abandoned sessions; the completed/abandoned counts are shown separately.
- The streak counts consecutive days with at least one completed session. If you
  haven't finished one yet today, it counts from yesterday so it doesn't reset early.

## API (used by the web UI)

| Request | What it does |
|---------|--------------|
| `GET /api/summary?week=0` | Weekly stats as JSON (`week=-1` for last week) |
| `GET /api/sessions?n=10` | Most recent sessions, newest first |
| `POST /api/sessions` | Log a session: `{label, start, end, minutes, completed}` |

The server only listens on 127.0.0.1, so other computers can't reach it.
